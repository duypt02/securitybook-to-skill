# Classify Red Team Knowledge

Classify source material into Red Team Skill knowledge types.

Use the profile schema knowledge types:
- conceptual
- procedural
- command
- tool
- scenario
- troubleshooting
- reporting
- safety

Rules:
- Use only the provided source content.
- Keep dual-use material tied to education, defense, lab use, or authorized testing.
- Preserve source context for commands, tools, and procedures.
- Mark unclear or unsupported items as "context incomplete".
